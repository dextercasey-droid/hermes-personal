Privacy policy

Last updated: 8 November 2026

Hermes Personal is a private assistant with exactly one user: its owner. No other person can sign in or use it.

What data it accesses

With the owner's explicit consent through Google sign-in, it accesses the owner's own Gmail, Google Calendar, Google Drive, Contacts, Sheets and Docs, only to carry out tasks the owner requests.

How data is used and stored

  • Data is used solely to provide the assistant's features to the owner.
  • Access credentials are stored only on the owner's own private server.
  • To process a request, relevant content may be sent to the AI model provider the owner has chosen, under that provider's terms.

Sharing

Data is never sold, never used for advertising, and never shared with anyone else. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections.

Contact

Questions: open an issue on this site's GitHub repository.
